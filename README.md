# 🏫 IIM Lucknow FAQ Chatbot

A simple NLP-based chatbot that answers frequently asked questions about **IIM Lucknow**.

## ✨ Features

- 🤖 FAQ based chatbot
- 🧠 NLP text preprocessing
- 🔎 TF IDF text matching
- 📐 Cosine similarity
- 💬 Interactive chat interface
- 🛡️ Handles unrelated questions
- 📚 50 IIM Lucknow FAQs

## 🛠️ Built With

- 🐍 Python
- 🧠 NLTK
- 📊 Scikit-learn
- 🎨 Streamlit
- 📄 JSON

## ⚙️ How It Works

```text
User Question
      ↓
Text Preprocessing
      ↓
TF-IDF Vectorization
      ↓
Cosine Similarity
      ↓
Find Best FAQ
      ↓
Display Answer
