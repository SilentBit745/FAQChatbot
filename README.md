# 🏫 IIM Lucknow FAQ Chatbot

> A simple chatbot to find answers to common questions about IIM Lucknow.

---

## 💬 What is this?

Just type your question and let the chatbot find the most relevant answer from the FAQ collection.

## ✨ Features

- 🔍 Finds similar questions
- ⚡ Gives quick answers
- 💬 Simple chat interface
- 🧠 TF-IDF based matching
- 🛡️ Handles unknown questions

## 🛠️ Built With

- Python
- NLTK
- Scikit-learn
- Streamlit

## 🚀 Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
